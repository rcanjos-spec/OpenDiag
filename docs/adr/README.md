# Architecture Decision Records (ADRs)

This directory contains the Architecture Decision Records (ADRs) for the OpenDiag project.

An ADR documents an important architectural decision, including its context, rationale, alternatives, and consequences.

The purpose of ADRs is to preserve the project's architectural knowledge and provide guidance for future contributors.

## ADR Template

Each ADR follows the structure below:

- Status
- Context
- Decision
- Rationale
- Consequences
- Alternatives Considered

ADRs should be updated only when a new architectural decision is made. Existing ADRs should not be modified unless the original decision changes.
